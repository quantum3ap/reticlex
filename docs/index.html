Overlay

One key, and it is on top of the game.

The reticle you designed, drawn over whatever is on screen, by the same rasteriser that drew it in the designer — so what you approved is what you get.

  • Click-through and never focusable: the mouse behaves as though it is not there
  • A global shortcut shows and hides it while another window has focus
  • Monitor picker and pixel offsets for multi-monitor and letterboxed setups
  • Four profile slots and a second shortcut that steps between them mid-match
  • Per-monitor DPI, drawn into a 640 px canvas in physical pixels

Contrast

Know before the fight whether you will see it.

Load a screenshot of the game you actually play and the read-out measures the pixels the reticle covers — reporting the worst of them, not the average. A crosshair that averages well still disappears against the one pale wall it crosses, and that pixel is the one that loses the fight.

  • Scored per pixel under a coverage mask, so the empty middle does not count
  • An outlined reticle is judged on whichever of its two colours stands out more
  • Warns below 3:1 — the readable floor the randomizer already works to
worst— typical—

Measured, not asserted: the same mint arms read 12.9:1 against the sky and 1.2:1 where they cross the pale wall. ReticleX reports the 1.2.

Library

Send a crosshair in a chat message.

A reticle is 200 bytes of configuration, so it fits in a line of text. Codes run between 16 and 90 characters — short enough to paste anywhere, and refused rather than half-decoded if they arrive cut short.

  • Import and export as JSON as well, with clear errors for anything malformed
  • A randomizer that only produces reticles you could actually aim with
  • Ten languages, including Arabic with a fully mirrored right-to-left layout
  • Undo and redo throughout; a slider drag collapses into one step

What it is made of

One core, compiled twice.

The geometry, the rasteriser, the validation and the randomizer live in one set of C and C++ sources, built as a native library for the application and as a WebAssembly module for the browser. That is why the reticle at the top of this page is the real thing and not a drawing of one.

Plainly

ReticleX draws a window on top of your screen. That is all it does. It does not read, modify or inject anything into any game, and it never has.

Your crosshairs and settings stay in %APPDATA%\ReticleX. No telemetry, no analytics, no account. The one network request it makes is an update check against the GitHub releases API, which sends nothing about you and which you can switch off in Settings — after that it touches the network never.

It installs per user, so it never asks for administrator rights. The source is on GitHub under the MIT licence; you can read every line of it, including this page.
